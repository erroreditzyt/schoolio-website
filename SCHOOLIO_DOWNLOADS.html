Need to know

Frequently asked questions.

Does the password really protect the HTML?

Yes. Protected download contents are encrypted in this website with AES-256-GCM. The password is not stored in the public page. Unlike a simple password popup, opening the website source does not reveal the protected download as readable HTML. A strong password and a secure (HTTPS) host are recommended.

Does this downloads page need a server?

No backend is needed to distribute these two files. You can publish the single downloads HTML file on a static hosting provider using HTTPS. It can also be opened locally in a modern browser that supports Web Crypto.

Can I add more SCHOOLIO versions later?

Yes. Supply the actual HTML file for another version and it can be added as a new release. Each new version can be public or password protected.

Will every feature in SCHOOLIO work offline?

Not necessarily. Although the downloads are HTML files, SCHOOLIO 2.8 contains features that may contact remote servers. Those features depend on their own services and internet connectivity.
